## 2. 문제 정의와 프로젝트 기획

### 2-1. 문제 한 문장 (팀 확정)

> <b>신입·교대 FSE(Field Service Engineer)</b>가 <b>고객사 팹에서 오버레이 계측장비를 셋업할 때</b> 겪는 <b>단계 누락과 인수인계 정보 손실</b>을 <b>단계별 셋업 체크리스트와 인수인계 요약 자동 생성</b>으로 줄이는 웹앱
>
> - 사용자: 신입·교대 FSE
> - 상황: 고객사 팹에서 오버레이 계측장비 셋업
> - 불편: 단계 누락, 인수인계 정보 손실 (가설)
> - 핵심 기능: 단계별 셋업 체크리스트, 인수인계 요약 자동 생성

### 2-2. 문제의 근거

| 근거 종류 | 상태 | 내용 |
|---|---|---|
| 자료 | 있음 | FSE/CSE 업무가 고객사 사이트 설치·Qualification·유지보수·캘리브레이션임 (F7, F8). 국내 3개 지점과 해외 TF 파견으로 현장 대응 (F5, F9) |
| 관찰 | 없음 | 현장 관찰 기회 없음. **확인 필요** |
| 인터뷰 | 없음 | 기업 멘토·FSE 인터뷰 필요. 위 질문 초안 사용. **확인 필요** |

현재 '단계 누락'과 '인수인계 정보 손실'은 <b>가설(H1, H2)</b>입니다. 자료로 확인된 것은 FSE가 고객사 현장에서 셋업·Qualification을 한다는 업무 구조뿐입니다.

### 2-3. 핵심 기능 (처음 범위: 2개)

1. **단계별 셋업 체크리스트**: 장비 모델과 셋업 건을 고르면 단계별 확인 항목이 나오고, 체크·측정값·메모를 남기면 진행률과 기준 이탈 항목이 바로 보임
2. **인수인계 요약 자동 생성**: 체크리스트 기록을 바탕으로 "완료 / 미완료 / 이슈 / 다음 할 일"을 한 장으로 정리해 다음 담당자에게 넘김

나중에 고려(이번 범위 아님): 사진 첨부, 고객사별 양식, 다국어, 오프라인 모드, 사내 시스템 연동

### 2-4. 입력 화면

- **셋업 건 정보**: 고객사(샘플명), 사이트, 장비 모델, 장비 S/N, 담당자, 교대 시작 시각
- **단계별 체크리스트**: 단계(예: 반입 → 유틸리티 연결 → 전원·SW 기동 → 캘리브레이션 → 측정 성능 확인 → 고객 Qualification)마다
  - 항목별 체크박스(완료 / 보류 / 해당 없음)
  - 측정값 입력칸(단위 표시, 기준 범위 표시)
  - 메모, 이슈 등록(심각도: 낮음 / 중간 / 높음)
- **인수인계 버튼**: 교대 종료 시 "인수인계 요약 만들기" 클릭

### 2-5. 결과 화면

- **진행 현황**: 전체 진행률(%), 단계별 완료 개수, 기준을 벗어난 측정값 빨간색 표시
- **인수인계 요약 카드** (한 장):
  - 완료된 단계·항목
  - 미완료·보류 항목과 그 이유
  - 열린 이슈(심각도순)
  - 다음 담당자가 먼저 할 일 3가지
  - 작성자·작성 시각
- 요약 복사 / 인쇄 버튼
